# Empresas Landing Page Images

This directory contains images for the corporate landing page at `/empresas/`.

## Required Images

### og-image.png
- **Purpose:** Open Graph image for social media sharing
- **Recommended size:** 1200x630 pixels
- **Format:** PNG or JPG
- **Content:** Should represent the corporate training program visually

**Action Required:** Add an appropriate Open Graph image to this directory.

## Image Guidelines

- Keep file sizes optimized (under 200KB for OG image)
- Use descriptive alt text in the template
- Ensure images are compressed without quality loss
